## 📐 Color Scheme

```
Primary Colors:
  • Blue (Accent): #4A6FFF
  • White: #FFFFFF
  • Black/Dark: #171717 or #0B1220

Light Mode:
  • Background: #FFFFFF
  • Text Primary: #1A1A1A
  • Text Secondary: #666666
  • Card Background: #F5F6FA
  • Border: #E0E0E0

Dark Mode:
  • Background: #0B1220 or #121212
  • Text Primary: #FFFFFF
  • Text Secondary: #B0B0B0
  • Card Background: #1F2937 or #1E1E1E
  • Border: #333333
```

## 🎯 Sizes & Typography

```
Titles:
  • Large: 28-36px, bold/600 weight
  • Medium: 20-24px, 600 weight
  • Small: 16px, 500 weight

Subtitles:
  • 15-18px, 400-500 weight
  • Color: Secondary text color
  • Line height: 22-26px

Buttons:
  • Height: 14-16px minimum
  • Padding: 14-16px vertical
  • Border radius: 12-30px
  • Width: 100% (full width)

Input Fields:
  • Height: 48-52px
  • Padding: 12-14px
  • Border radius: 12px
  • Border width: 1px
```

---

## ✨ Component Guidelines

- **Buttons**: Blue background, white text, rounded corners, full width
- **Inputs**: Gray background, dark text, thin border, placeholder text gray
- **Cards**: Slightly darker background, rounded corners, subtle shadow
- **Icons**: 20-48px size, blue when interactive
- **Progress bars**: Filled circles with connecting lines
- **Toggles**: Dark/Light theme toggle in top corners
- **Navigation**: Bottom tabs with icons and labels
